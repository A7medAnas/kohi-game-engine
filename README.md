# Kohi Game Engine - Linux Development

This repository documents my journey of building a 3D game engine from scratch using C and the Vulkan API on a Linux (Fedora) environment. 
The primary goal of this project is to deeply understand low-level systems programming, memory management, and game engine architecture.

##  Tech Stack
* **Language:** C
* **Graphics API:** Vulkan
* **Platform:** Linux (Fedora / X11)
* **Compiler:** Clang
